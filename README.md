# Dremart – Multi-Chain Web3 Wallet

Dremart is a secure multi-chain Web3 wallet Chrome extension for managing crypto assets, viewing portfolios, sending and receiving tokens, swapping assets, and bridging supported networks.

## Features

- Create or import a wallet
- Send and receive crypto assets
- View balances and portfolio value
- Manage supported tokens
- Swap assets on supported networks
- Bridge assets across supported networks
- View blockchain activity and transaction history
- Supports EVM networks, Solana, and Bitcoin

## Supported Networks

- Ethereum
- BNB Chain
- Base
- Polygon
- Arbitrum One
- Optimism
- Avalanche C-Chain
- Solana
- Bitcoin

## Install Dremart

Install the official Dremart Chrome extension:

[Install Dremart from the Chrome Web Store](https://chromewebstore.google.com/detail/dremart/iheoogicklhconefaejmnlgmmifihnld)

## Getting Started

1. Install Dremart from the Chrome Web Store.
2. Pin the extension in Chrome.
3. Create a new wallet or import an existing wallet.
4. Back up your recovery phrase securely.
5. Start managing your supported crypto assets.

## Security

Never share your recovery phrase, private keys, or wallet password with anyone. Always verify network names and wallet addresses before sending crypto.

## Disclaimer

Dremart is a non-custodial wallet interface. Users are responsible for protecting their wallet credentials and confirming every transaction before approval.
